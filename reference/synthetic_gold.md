# Synthetic calibration set with three human raters

A 200-item synthetic set of support-style question/answer items, each
rated Incorrect / Partial / Correct by three simulated human raters. It
is sized so that an audit can reach a verdict rather than stop at
`INDETERMINATE`, and it is the input for the README's end-to-end run.
Every label is planted: a true label was drawn per item, the answer text
written to match it (correct answers name a place and an action, partial
answers hedge, incorrect answers deflect), and each rater is the truth
with a 6% chance of an adjacent-level slip. The text is templated from
24 questions, so no row is a real ticket; what is independent across
rows is the draw of the label and of each rater's error. Inputs are at
most 180 characters, so a judge whose behaviour changes above 240
characters is moved by the verbosity probe's filler and not by the
shorter framing prefixes of the other probes. Not a benchmark and not a
basis for any deployment decision.

## Usage

``` r
synthetic_gold
```

## Format

A tibble with 200 rows and 6 columns:

- id:

  Character item identifier, `"syn-001"` to `"syn-200"`.

- input:

  Character. The question and candidate answer presented to the judge,
  formatted as `"Question <n>: ...\nAnswer: ..."`.

- target:

  Character. The grading criterion; the same sentence for every item.

- rater_1, rater_2, rater_3:

  Simulated human ratings, ordered factors with levels `I` \< `P` \<
  `C`.

## Source

Generated by `data-raw/synthetic_gold.R` with a fixed seed.

  synthetic_gold,
  human_cols = c("rater_1", "rater_2", "rater_3"),
  judge = function(data) {
