# Example gold-labeled support answers

A small synthetic dataset of support-style question/answer items, each
rated Incorrect / Partial / Correct by a human and by an example LLM
judge. It is the input for the live-judge example in the README and
exists to demonstrate the
[`calibrate_judge()`](https://jsizzler.github.io/yourhonor/reference/calibrate_judge.md)
API without a model call. It is eight items: not a benchmark and not a
basis for any deployment decision. The judge labels disagree with the
human labels on two items (1 and 7, where the judge is one level more
lenient), so agreement is realistic rather than 1.0.

## Usage

``` r
support_gold
```

## Format

A tibble with 8 rows and 5 columns:

- id:

  Integer item identifier, `1:8`.

- input:

  Character. The question and candidate answer presented to the judge,
  formatted as `"Question: ...\nAnswer: ..."`.

- target:

  Character. The grading criterion; the same sentence for every item.

- human_label:

  Human rating, an ordered factor with levels `I` \< `P` \< `C`.

- judge_label:

  Example judge rating, same ordered levels.

## Source

Generated by `data-raw/support_gold.R`.

## Examples

``` r
support_gold
#> # A tibble: 8 × 5
#>      id input                                     target human_label judge_label
#>   <int> <chr>                                     <chr>  <ord>       <ord>      
#> 1     1 "Question: How do I reset my password?\n… Does … P           C          
#> 2     2 "Question: Why was my card declined?\nAn… Does … C           C          
#> 3     3 "Question: Can I export my data to CSV?\… Does … I           I          
#> 4     4 "Question: What are your support hours?\… Does … C           C          
#> 5     5 "Question: How do I cancel my subscripti… Does … P           P          
#> 6     6 "Question: Is two-factor authentication … Does … C           C          
#> 7     7 "Question: Where can I download my invoi… Does … I           P          
#> 8     8 "Question: How do I add a teammate to my… Does … C           C          
calibrate_judge(
  support_gold,
  id_col = "id",
  label_levels = c("I", "P", "C"),
  scale = "ordinal",
  n_boot = 100,
  seed = 1
)
#> 
#> ── yourhonor judge calibration ─────────────────────────────────────────────────
#> 8 usable items of 8 - descriptive judge-vs-human agreement:
#> • cohen_kappa: 0.76 [0.34, 1.00] (substantial)
#> • krippendorff_alpha: 0.77 [0.27, 1.00] (substantial)
#> • gwet_ac2: 0.81 [0.55, 1.00] (almost perfect)
#> 2 disagreements; inspect `confusion_metrics()` before use.
#> ℹ No deployment decision is implied; call report() with a policy to assess one.
```
